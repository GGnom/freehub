# Changelog

## 0.2.0 — первый публичный релиз

### Возможности

- OpenAI-совместимый локальный шлюз (`/v1/models`, `/v1/chat/completions`) с tool calling,
  стримингом и fallback'ом между провайдерами.
- Каталог бесплатных и дешёвых провайдеров, ключи из env / `keys.json` / webkey.
- Живой индекс моделей с кэшем и персистом, `modelExclude`, фильтр OpenRouter `:free`.
- Сжатие истории изображений под лимит провайдера, `streamMode: "synthesize"` для апстримов
  с некорректными SSE-дельтами tool_calls.
- Встроенный веб-UI: провайдеры и ключи, чат-playground, модели, подключение, лог, мост.
- Мост веб-чатов chat-bridge: автозапуск, health-check, регистрация как провайдера.
- Свои OpenAI-совместимые API: через UI, `POST /api/providers` или конфиг.

### Исправления и укрепление

- Управляющий API `/api/*` больше не принимает cross-origin запросы и требует локальный `Host`
  (защита от атак со сторонних сайтов и DNS rebinding).
- `Access-Control-Allow-Origin` оставлен только на OpenAI-совместимых маршрутах.
- Остановка моста не убивает посторонний процесс, случайно занявший порт.
- Превышение лимита тела запроса возвращает `413`, а не рвёт соединение.
- Ошибки асинхронного проксирования больше не превращаются в `unhandledRejection`.
- Конфиг и ключи пишутся атомарно (temp + rename).
- Добавлены офлайн-тесты (16 проверок) и CI для Node 18/20/22 на Linux и Windows.
